# Security Policy

The Divmora security team takes all vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

---

## 🛡️ Supported Versions

We provide security updates for the following versions of **AuthPin**:

| Version | Supported |
| :--- | :---: |
| `0.1.x` | ✅ Yes |
| `< 0.1.0` | ❌ No |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability, **do not open a public issue**. Instead, follow one of the private disclosure channels below:

1. **GitHub Private Vulnerability Reporting (Recommended):**
   Navigate to the [Security Advisories tab](https://github.com/divmora/authpin/security/advisories) on GitHub and click **"Report a vulnerability"**.

2. **Email Disclosure:**
   Send an encrypted report to **`security@divmora.com`** with:
   - Description of the vulnerability and affected endpoints.
   - Proof of Concept (PoC) or reproduction steps.
   - Impact assessment.

### ⏱️ Response SLA
- **Initial Acknowledgment:** Within **48 hours**.
- **Assessment & Triage:** Within **5 business days**.
- **Coordinated Disclosure:** Fixes will be coordinated and released with credit given to the reporter.
